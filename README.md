# quote-box

A self-hosted, LAN-only web app for browsing, managing, and displaying a personal collection of quotes. Designed to run on a small Ubuntu server on a home network, with a fullscreen rotating display mode suited to a wall-mounted screen.

This repository currently contains the project specification and seed data only — the application itself is not yet implemented. See [SPEC.md](SPEC.md) for the full feature spec and [CLAUDE.md](CLAUDE.md) for engineering conventions and project rules.
